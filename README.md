A legibility-first poster summing up Wednesday 25 November 2026 in one image: the Houthi strike on Riyadh's PIF Tower dominates the page (11 wounded, the second strike on the tower in a week), four large cards cover Ukraine, Huawei, Giuliani and the CIA breach, and an eight-item strip rounds out the day from NATO jets in Poland to the New Zealand–India Test draw. Pure Python 3.13 standard library — it draws the whole poster itself, with its own bitmap font and PNG encoder, so the image is byte-identical on every run.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
